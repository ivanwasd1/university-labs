# Вариант 22. Четырёхугольник на плоскости

Нужен JDK 11 или новее. Команды `java`, `javac` и `jar` должны быть доступны в PATH.

## Запуск

В Windows распаковать архив и открыть `run.cmd`. Программа соберётся и покажет массив из 20 случайных фигур, количество объектов каждого типа и четыре экстремума для каждой группы. Номера в результатах соответствуют номерам фигур в массиве. Для тестов открыть `test.cmd`.

Через GNU Make из папки проекта:

```
make build
make run
make test
make clean
```

`build` перекомпилирует все классы и создаёт `build/quadrilaterals.jar`. `clean` удаляет файлы классов и JAR. Готовый JAR можно запустить отдельно:

```
java -ea -jar build/quadrilaterals.jar
```

## Файлы

- `src/Point.java` — координаты точки и расстояние между точками.
- `src/Quadrilateral.java` — конструктор, площадь, периметр и тип четырёхугольника.
- `src/Main.java` — создание случайного массива и обработка групп обычными циклами.
- `src/QuadrilateralTest.java` — тестовое приложение на JUnit 4, выводящее исходные данные и результаты.
- `lib/` — JUnit 4.13.2 и его зависимость Hamcrest 1.3. Скачивать их отдельно не нужно.

Для запуска тестов в IntelliJ IDEA отметить `src` как Sources Root, а оба JAR из `lib` добавить через Add as Library. Затем запустить `QuadrilateralTest.main`. Основная программа запускается через `Main.main`.

## Решение

Вершины задаются по порядку обхода границы. Площадь находится через сумму ориентированных площадей треугольников ABC и ACD, периметр — сложением длин сторон. Допускаются вогнутые фигуры. Совпадающие вершины, коллинеарные тройки и самопересечения вызывают исключение.

Квадрат учитывается только в группе квадратов. Прямоугольники и ромбы, не являющиеся квадратами, идут в свои группы. Остальные фигуры считаются произвольными. Сравнения выполняются с абсолютным допуском `0.00000001`; очень маленькие и почти вырожденные фигуры отклоняются.

Для случайной фигуры сначала выбирается тип, затем целые координаты и размеры. Без выбора типа случайные точки почти никогда не образовали бы квадрат или прямоугольник. При равных значениях минимумом или максимумом остаётся первый объект. Для пустой группы выводится «Нет объектов».

Тесты используют JUnit, а проверка внутреннего условия в конструкторе — `assert`. Ключ `-ea` включает `assert`.
