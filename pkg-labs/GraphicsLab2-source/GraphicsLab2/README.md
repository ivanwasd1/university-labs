# Лабораторная работа 2

Чтение метаданных JPEG, GIF, TIFF, BMP, PNG и PCX. Приложение на Java Swing
показывает размер, DPI, глубину цвета, сжатие и результат проверки файла.

## Запуск

- В Windows распакуйте архив portable-версии и откройте `GraphicsLab2.exe`
  внутри папки `GraphicsLab2`. Папки `app` и `runtime` должны лежать рядом с EXE.
- В IntelliJ IDEA откройте `pom.xml` как Maven-проект, выберите JDK 21 или новее
  и запустите `ru.bsu.graphicslab.Main`.
- В терминале выполните `mvn test` для тестов или `mvn package` для сборки.
  Готовый JAR запускается командой `java -jar target/GraphicsLab2.jar`.

В приложении выберите файлы или папку. Сканируется выбранная папка, без вложенных
каталогов. После обработки нажмите на заголовок столбца для сортировки. Чтобы
увидеть полный путь или причину ошибки, наведите курсор на соответствующую ячейку.

В `docs` находится отчёт с описанием форматов и результатами проверок.
