# Лабораторная работа 1

Настольное приложение на Java Swing для варианта 1: RGB ↔ LAB ↔ CMYK.

## Возможности

- одновременное отображение RGB, LAB и CMYK;
- числовой ввод, ползунки и стандартная палитра;
- автоматический пересчёт всех трёх моделей;
- динамические градиенты ползунков;
- освещение D65, D50 или E с пересчётом матриц RGB ↔ XYZ;
- алгоритмы цветоделения UCR и GCR;
- обработка выхода из RGB с помощью Clipping или Scaling;
- предупреждение при выходе цвета за диапазон RGB;
- разделение кода на Model, View и Controller;
- автоматические тесты JUnit 5.

Все преобразования цветов реализованы вручную. Библиотеки конвертации не
используются.

## Запуск

Готовая portable-версия находится в архиве `release\ColorModelsLab-portable.zip`.
После распаковки нужно запустить `ColorModelsLab.exe`. Отдельная установка Java для
portable-версии не требуется.

Для запуска из исходников нужны JDK 17 или новее и Maven:

```bat
test.bat
run.bat
```

`test.bat` запускает тесты, `run.bat` собирает и запускает программу,
`build.bat` создаёт `target\ColorModelsLab.jar`, а `package.bat` формирует
portable-приложение и архив исходников.

## Структура

```text
src/main/java/ru/university/colormodels/
├── model/       формулы, матрицы и алгоритмы
├── controller/  состояние цвета и обработка действий
└── view/        окно, панели и градиенты

src/test/java/   тесты JUnit 5
docs/            отчёт по лабораторной работе
pom.xml          настройки Maven
```

Контрольное значение для красного цвета при D65:

```text
RGB(255, 0, 0) → XYZ(41.24, 21.26, 1.93) → LAB(53.24, 80.09, 67.20)
```
