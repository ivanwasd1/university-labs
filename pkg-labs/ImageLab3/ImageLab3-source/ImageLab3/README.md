## Запуск

- Windows x64: распакуйте portable-архив и откройте `ImageLab3.exe`. Папки
  `app` и `runtime` лежат рядом с EXE. Windows XP не поддерживается Java 21.
- IntelliJ IDEA: откройте `pom.xml` как Maven-проект, выберите JDK 21 и
  запустите `ru.bsu.imagelab.Main`.
- Терминал: `mvn test` запускает тесты. `mvn package` создаёт
  `target/ImageLab3.jar`. Запуск JAR: `java -jar target/ImageLab3.jar`.

Откройте свой файл или выберите встроенный пример, задайте алгоритм и нажмите
«Применить». Операция использует исходное изображение. Сохранение записывает PNG
в полном разрешении. Две гистограммы используют общий максимум по вертикали.

## Исходники и испытания

`MainFrame` связывает настройки, фоновые операции и экран, `HistogramPanel`
рисует гистограмму. `ImageBuffer` хранит ARGB, `Boundary` отображает координаты
при выходе за край. `SmoothingFilters` выполняет два одномерных прохода,
`Morphology` вычисляет операции через минимум и максимум.
`ParallelProcessor` распределяет строки между потоками.

В `src/main/resources/examples` лежат 10 оригинальных синтетических PNG.
Для шумовых изображений использованы фиксированные генераторы. В двух шумовых
испытаниях чистый эталон — `reference.png`.

Наивная 2D-свёртка существует только в тестовой части. После `mvn test`
замер можно повторить из IntelliJ через `ProcessingBenchmark.main` или
в Windows командой:

```powershell
java -cp "target/classes;target/test-classes" ru.bsu.imagelab.core.ProcessingBenchmark
```

В `docs` включён отчёт с формулами, графиками и результатами.
