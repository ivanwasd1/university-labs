# Лабораторные работы по C++

Учебный репозиторий с лабораторными, семинарскими и практическими заданиями первого курса ФПМИ БГУ.

Репозиторий является fork совместной учебной базы и содержит как мои решения и доработки, так и общие материалы курса.

## Содержание

- базовые задачи по C++;
- работа с классами и перегрузкой операторов;
- динамические структуры данных;
- лабораторные по векторам и строкам;
- тесты и материалы семинаров.

Репозиторий сохранён как история университетской практики и не является отдельным продуктовым проектом.
