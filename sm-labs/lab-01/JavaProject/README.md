# СЛАУ 12 — пункт а)

Проект для Java 17 или новее. Используется только стандартная библиотека.

Реализован метод Гаусса без выбора главного элемента. Один прямой ход применяется к расширенной матрице `[A | b | E]`. Программа получает решение `x`, определитель `A`, обратную матрицу, число обусловленности в бесконечной норме и матрицу невязки `R = E - A^-1 A`.

## Запуск

Готовая сборка:

```text
java -jar Slau12.jar
```

Сборка из исходников и запуск: `run.bat` в Windows или `bash run.sh` в Linux/macOS. Для сборки требуется JDK 17 или новее. Команды выполняются из папки проекта.

В IntelliJ IDEA откройте папку проекта, назначьте JDK и запустите `Main.main`. В VS Code с установленной поддержкой Java доступны конфигурации F5 «СЛАУ 12 пункт а» и «Проверки».

## Проверки

```text
java -jar Slau12.jar --test
```

Выполняются 16 групп проверок: системы с заранее известным решением, обратная матрица и определитель примера 2×2, 30 дополнительных систем, неизменность входных массивов, исходный вариант, вырожденность, нулевой и слишком малый ведущий элемент, диапазон double и ошибочный ввод.

## Другие данные

```text
java -jar Slau12.jar --input examples/simple2.txt --out results/simple2
```

В файле сначала записывается порядок `n` от 1 до 100, затем `n` строк по `n + 1` числу: коэффициенты A и правая часть b. Разделители — пробелы и переводы строк. Допустимы десятичные точка и запятая.

```text
2
4 1 6
2 3 8
```

Для этого примера `x = (1; 2)`, `det A = 10`, `A^-1 = [[0.3, -0.1], [-0.2, 0.4]]`, `nu_inf(A) = 3`.

При неверном вводе или неприменимости схемы программа пишет сообщение и завершается с кодом 1. Гаусс без перестановок может встретить нулевой ведущий элемент даже у невырожденной матрицы. Контроль малого ведущего элемента использует порог `100 * Math.ulp(1.0) * norm(matrix)` и не является точным определением ранга. Числа вне допустимого диапазона вычислений double отклоняются.

## Файлы

- `src/Main.java` — исходные данные, чтение файла и вывод.
- `src/GaussMethod.java` — прямой и обратный ходы, определитель и обратная матрица.
- `src/LinearAlgebra.java` — копирование, нормы и матрица невязки.
- `src/SelfTest.java` — встроенные проверки.
- `results/results.txt` — вывод основного расчёта.
- `results/results.json` — значения для таблиц с полной точностью записи double.
- `results/self-test.txt` — протокол проверок.
- `results/independent-check.txt` — независимая сверка с точной рациональной арифметикой.

В `R` множители расположены именно как `A^-1 A`. Матричная бесконечная норма — максимум суммы модулей строки. Максимум отдельного элемента выводится отдельно. Невязка считается по исходной A и неокруглённой вычисленной обратной матрице.

Результаты нового запуска записываются в каталог `--out`, по умолчанию `results`. Для стороннего примера используйте отдельную папку. Если запуск завершился ошибкой, ранее сохранённые результаты могут остаться; проверьте сообщение и код завершения.
