# Методы решения СЛАУ

Вариант СЛАУ-12. Java 17 или новее, только стандартная библиотека.

## Запуск

Готовая программа: `java -jar Slau12.jar`.

Запуск с перекомпиляцией исходников: в Windows откройте `run.bat`, в Linux/macOS выполните `bash run.sh`. Требуется установленный JDK 17 или новее и команда `java` в PATH.

В IntelliJ IDEA откройте эту папку как Java-проект, выберите JDK 17+ и запустите `Main.main`. При необходимости отметьте `src` как Sources Root. В VS Code с установленной поддержкой Java откройте папку и нажмите F5.

## Примеры команд

```text
java -jar Slau12.jar
java -jar Slau12.jar --test
java -jar Slau12.jar --input examples/simple2.txt --out results/simple2
java -jar Slau12.jar --input examples/singular.txt
java -jar Slau12.jar --epsilon 0.000001 --out results/eps6
```

Формат входного файла: сначала порядок n от 1 до 100, затем n строк расширенной матрицы. В каждой строке n коэффициентов A и один элемент b. Разделитель — пробельный символ, десятичный разделитель — точка или запятая. Начальное приближение всегда x0 = b. По умолчанию epsilon = 1e-5, предел итераций — 10000; можно передать `--limit` от 1 до 100000. Параметр `--out` меняет каталог результатов.

## Методы

1. Гаусс без выбора главного элемента.
2. Хаусхолдер, QR-разложение с помощью отражений.
3. Якоби.
4. Зейдель.

На карточке сказано, что методы назначает преподаватель; их названия в приложениях не приведены. Этот набор выбран для выполнения всех четырёх частей задания. До сдачи нужно сверить назначение методов. Метод Гаусса выбран без перестановок в соответствии с исправленным образцом.

Алгоритм Гаусса намеренно не переставляет строки. Ошибка при нулевом ведущем элементе не всегда означает вырожденность матрицы: для такой матрицы может понадобиться другой вариант метода. Произвольные входные данные не обязаны обеспечивать сходимость Якоби и Зейделя. При исчерпании лимита программа сообщает об этом; все четыре результата сохраняются только после успешного завершения вычислений.

## Результаты

В `results` находятся реальные результаты для СЛАУ-12:

- `results.txt` — вывод программы;
- `results.json` — числа без округления для таблиц отчёта;
- `jacobi.csv` и `seidel.csv` — все приближения, нормы шага и невязки;
- `self-test.txt` — результат встроенных проверок.

При повторном запуске одноимённые результаты в выбранном каталоге перезаписываются. Ранее сохранённые файлы не удаляются при ошибке нового расчёта; ориентируйтесь на код завершения и сообщение программы.

Счётчики операций относятся к решению одной системы: сложения/вычитания, умножения, деления, квадратные корни. В итерационных методах учтены вычитания для критерия остановки. Вычисления обратной матрицы, диагностических норм, журналов и вывод в эти счётчики не входят. Сумма счётчиков не является замером времени процессора.

## Структура

- `Main` — данные, ввод, запуск методов, сохранение результатов.
- `LinearAlgebra` — копирование массивов, нормы, невязки, счётчики.
- `DirectMethods` — Гаусс, Хаусхолдер и обратная подстановка.
- `IterativeMethods` — Якоби, Зейдель и их матричные формы.
- `SelfTest` — проверки известных решений и ошибочных ситуаций.

Полная компиляция вручную:

```text
java -m jdk.compiler/com.sun.tools.javac.Main -encoding UTF-8 -d out @sources.txt
java -cp out Main
```
